# BABAPLAYER IPTV releases

Downloads for Babaplayer outside the app stores. Every download, with install steps, is on **https://babaplayer.com/download**. The app's source is private; this repo only holds release files.

## Mac

Download the newest **BABAPLAYER IPTV for Mac** from babaplayer.com/download, or from [Releases](https://github.com/egemenuzunali/babaplayer-releases/releases/latest): `arm64` for Apple Silicon (M1 and later), `x64` for Intel. Needs macOS 12 or later.
The app is signed and notarized by Apple: it opens normally and updates itself automatically.

## Fire TV / Fire Stick

1. On the Fire TV, install **Downloader** from the Amazon Appstore.
2. Go to **Settings → My Fire TV → Developer options → Install unknown apps** and turn it on for Downloader.
   No Developer options? Open **Settings → My Fire TV → About** and click the device name 7 times.
3. Open Downloader, enter **babaplayer.com/firetv** and install.

The latest Android TV build is always at
`https://github.com/egemenuzunali/babaplayer-releases/releases/download/firetv/babaplayer-tv.apk`.

Needs Fire OS 6 or newer (Fire TV Stick 2nd generation and later). From version 1.102.0 on, the app offers new versions itself: choose Update when it asks. A copy older than 1.102.0 has to be updated once by hand: install the new file the same way.
Subscriptions are managed at https://babaplayer.com.
